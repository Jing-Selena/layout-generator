# 布局图生成器

这是一个用于生成货架布局图的Web应用，可以根据商品资料表和落位明细清单自动生成货架框架图和多个维度的商品布局图。

## 功能特点

1. **Web界面**：友好的Web用户界面，无需编程知识即可使用
2. **自动识别Excel文件**：自动识别商品资料表和落位明细清单
3. **数据匹配**：根据商品编码自动匹配两个表的数据
4. **多维度布局图**：生成项目中类、项目小类、项目细类、销售类别、品牌等多个维度的布局图
5. **批量下载**：支持下载所有布局图的ZIP压缩包，也支持单独下载每个图片

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 启动Web应用

```bash
streamlit run app.py
```

应用会在浏览器中自动打开，默认地址为：http://localhost:8501

### 使用步骤

1. **上传文件**：
   - 在左侧上传"商品资料表"Excel文件
   - 在右侧上传"落位明细清单"Excel文件

2. **生成布局图**：
   - 点击"生成布局图"按钮
   - 等待处理完成

3. **下载结果**：
   - 可以下载所有布局图的ZIP压缩包
   - 也可以单独下载每个布局图

## 输入文件要求

### 商品资料表（Excel文件）

- 文件名需包含"商品资料表"
- 必须包含列：`商品编码`
- 应包含列：
  - `项目商品类别`
  - `项目中类`
  - `项目小类`
  - `项目细类`
  - `品牌名称`

### 落位明细清单（Excel文件）

- 文件名需包含"落位明细清单"
- 必须包含列：
  - `*商品编码`（或`商品编码`）
  - `*货架序号`（或`货架序号`）
  - `*层数`（或`层数`）
  - `*位置`（或`位置`）
- 可选包含列：`货架模板名称`

## 输出文件

程序会生成以下布局图：

1. **货架框架图.png**：显示所有货架的结构框架，标注了层数和位置
2. **项目中类布局图.png**：按项目中类维度生成的商品布局图
3. **项目小类布局图.png**：按项目小类维度生成的商品布局图
4. **项目细类布局图.png**：按项目细类维度生成的商品布局图
5. **销售类别布局图.png**：按销售类别（项目商品类别）维度生成的商品布局图
6. **品牌布局图.png**：按品牌名称维度生成的商品布局图

如果数据中包含货架模板名称，文件名会包含该名称，例如：`未来图-糖巧布丁6中岛-项目小类布局图.png`

## 工作原理

1. 用户上传两个Excel文件
2. 程序读取并解析Excel数据
3. 根据商品编码进行数据匹配，将商品资料表中的类别、品牌等信息合并到落位明细清单中
4. 根据货架序号、层数、位置信息构建货架结构
5. 生成货架框架图（仅显示结构）
6. 按不同维度生成商品布局图（显示商品，按维度用不同颜色区分，相邻相同类别会合并）

## 技术栈

- Python 3.6+
- Streamlit：Web应用框架
- pandas：Excel文件读取和数据处理
- matplotlib：图表生成
- openpyxl：Excel文件解析
- numpy：数值计算

## 注意事项

- 确保Excel文件格式正确，列名包含所需的关键词
- 商品编码必须能够匹配，否则该商品将无法显示类别和品牌信息
- 生成的图片分辨率较高（300 DPI），适合打印使用
- 如果文件较大，处理可能需要一些时间，请耐心等待
